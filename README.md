| Milestone | Deliverable | Key Success Criteria |
| :--- | :--- | :--- |
| **Round 1** | **1-Slide Idea Submission** | Clear problem understanding, technically credible architecture, high engineering feasibility, crisp value proposition. |
| **Round 2** | **Detailed ~10-Slide Deck** | Deep architectural diagrams, data flows, edge-case handling, simulation/tech stack details. |
| **Finals** | **Grand Finale Pitch** | Working prototype/simulation, executive-ready presentation to Tata Elxsi leadership. |
| **Ultimate Outcome** | **PPI / PPO Opportunity** | Showcase strong CS, AI/ML, and Systems Engineering depth. |
